Rice Mill Monitoring Portal

Everyone signs in the same way, then Admin and User / Worker accounts follow separate paths with different permissions, and both end at logout.

Shared screensAdmin onlyUser / Worker

What each screen does

1Login Screen

Authenticates the person before access is granted. Valid credentials continue to role routing; invalid credentials show an error.

2Role Routing

Sends each signed-in person to the correct dashboard and restricts admin controls to Admin accounts.

3Admin Dashboard

Gives administrators an overview of mill operations and shortcuts to monitoring, analytics, alerts, and settings.

4User / Worker Dashboard

Lets workers check operational status and issues. Configuration and account-management controls are hidden.

5Process Overview

Shows production stages in sequence and helps identify which stage is running, stopped, or needs attention.

6Analytics

Helps users compare energy use and production over time. Sample values are illustrative until live data is connected.

7Alerts & Thresholds (Admin)

Admin reviews abnormal conditions and configures limits that trigger warnings. Threshold editing is Admin-only.

8Alerts (User / Worker)

Helps workers understand current problems and when they occurred. Threshold configuration is unavailable.

9Settings (Admin)

Allows administrators to maintain their account and manage portal access.

10Settings (User / Worker)

Lets workers maintain their own account without user-management or threshold settings.

11Logout Confirmation

Prevents accidental sign-out. Cancel returns to the current screen; Logout ends the session and redirects to Login.

12End / Login Return

Closes the user journey securely. The next visit starts at the Login Screen.
